# 포스터치, 일반 탭 및 LCD

## 클릭과 드래그

일반 한 손가락 탭 클릭은 펌웨어에서 손을 떼는 즉시 판정합니다. 기본 조건은
200ms 이내 접촉과 최초 좌표에서 16 센서 단위 이내 이동이며, 커서 이동을
보류하지 않습니다. 두 번 연속 탭하면 각 손 뗌에서 한 번씩 클릭합니다.
센서 자체의 한 손가락 탭 판정은 꺼서 판정 중 상대 이동값 억제를 피합니다.
포스터치 클릭을 이미 한 접촉에서는
손가락을 뗄 때 탭 클릭이 추가로 나오지 않도록 막습니다. 두 손가락 우클릭과
스크롤도 유지합니다. 시간만으로 클릭하는 길게 누르기는 사용하지 않습니다.

포스터치는 현재 접촉 강도에서 보정된 기준값을 뺀 증가량으로 판정합니다.
기준값이 1000이면 80 이상 증가한 상태가 16ms 유지될 때 버튼을 누르고,
증가량이 30 이하인 상태가 16ms 유지될 때 버튼을 해제합니다.
센서의 접촉 강도이며 물리적인 압력 단위는 아닙니다.

이동이 먼저 시작되면 이동 중 바뀌는 강도는 새로운 접촉 기준으로 따라갑니다.
최근 이동이 끝난 뒤 16ms가 지나면 새 누름을 시작할 수 있습니다.
이 대기 중 좌표가 안정되면 강도 기준값은 유지하므로, 정지 직후 올린 힘을
기준값에 흡수하지 않습니다. 6 센서 단위 이내의 왕복 흔들림은 허용합니다.
처음 손가락을 댄 좌표에 계속 머무를 필요는 없습니다. 정지 상태에서 누름 후보가
시작된 뒤에는 손가락 변형으로 중심 좌표가 조금 이동해도 후보를 유지합니다.
후보 중 큰 이동(드래그 시작 거리의 3배 초과)은 계속되는 이동으로 취소합니다.

누름 확인 중의 미세 이동을 버리고, 클릭 확정 위치에서 24 센서 좌표 단위를
초과하여 움직이면 드래그합니다. 드래그가 시작된 뒤에는 해제 후보가 발생해도
커서 이동을 끊지 않습니다. 힘을 뺐을 때는 버튼만 해제하며, 클릭 해제마다
기준값을 다시 측정하지 않습니다. 같은 접촉에서 두 번 빠르게 누를 수 있습니다.

## 멈춤 및 TP 레이어 복구

센서 처리와 센서 절전 처리는 별도 작업 큐에서 실행합니다. 센서 작업의 선점형
우선순위를 5에서 0으로 높이고, 프레임 읽기 및 설정 쓰기 직후 통신 창을 닫습니다.
따라서 입력 전송 대기 전에 센서가 다음 측정을 시작할 수 있습니다.
입력 이벤트 등록은
최대 5ms만 기다리므로 센서 스트리밍이나 전송 지연이 시스템 작업 큐를 무한히
막지 않게 합니다. 이동량이 없는 축은 전송하지 않고, 매 프레임 로그는 디버그
레벨로 낮춥니다. 입력 큐와 중앙의 주변 장치 이벤트 큐 크기는 32로 설정합니다.

오른쪽은 클릭 중뿐 아니라 손가락 접촉 중 전체를 감시합니다. 250ms 이상 새
센서 보고가 없으면 클릭과 터치 상태를 모두 해제하고 센서 읽기를 다시 시도합니다.
통신 오류와 절전 전환에서도 터치 해제를 보냅니다.

왼쪽의 자동 TP 레이어는 별도의 접촉 감시기로 관리합니다. 접촉 상태가 250ms마다
갱신되며, 750ms 동안 새 상태가 없으면 자동으로 켰던 TP 레이어를 해제합니다.
이 동작은 NAV/NUM의 스크롤용 입력 처리와 독립적입니다. 전송 중 클릭 해제만
누락된 경우에도 뒤따르는 상태 보고나 시간 만료로 마우스 버튼 해제를 재시도합니다.
표시용 상태는 전용 ABS 코드 0x18로 전달되며 `sync=false`를 사용합니다.

## 설정

`boards/shields/toucan/toucan_right.overlay`에 적용된 값입니다.

| 항목 | 값 |
|---|---:|
| 최소 누름 증가량 / 해제 증가량 | 30 / 16 |
| 누름 증가율 / 해제 증가율 | 8% / 3% |
| 초기 안정 접촉 측정 시간 | 40ms |
| 최초 접촉 후 최소 준비 시간 | 64ms |
| 누름·해제 확인 시간 | 16ms |
| 최근 이동 감지 허용량 | 6 센서 좌표 단위 |
| 이동 후 정지 대기 | 16ms |
| 클릭 확정 후 드래그 시작 거리 | 24 센서 좌표 단위 |

최근 이동 감지는 허용 범위를 벗어나는 누적 이동과 같은 방향의 연속 이동을 사용합니다.
거리 설정은 화면 픽셀이 아닙니다. 강도 임계값에는 최소 증가량과 기준값 대비
증가율 중 큰 값을 사용합니다. 센서 보고 간격은 접촉 중 8ms입니다.

## LCD

기존 y=78의 아이콘 줄을 y=64로 14픽셀 올립니다. 배터리 아래에 약 8픽셀의
여백을 두고, 전체 아이콘 줄은 144픽셀 화면의 중앙에 맞춥니다.
모디는 24×24픽셀, 손가락은 32×32픽셀입니다.

Win·Alt·Ctrl·Shift 순서로 항상 윤곽선을 표시하며, 누른 모디만 내부를 채웁니다.
손가락 없음은 윤곽선, 일반 접촉은 채움, 포스터치 클릭은 윤곽선과 두꺼운 후광으로
표시합니다. 후광은 실제 클릭 상태를 나타내며 강도 증가만으로 켜지지 않습니다.

## 검증 및 적용

자동 검사는 초기 접촉과 잡음, 이동 직후 흔들리는 좌표에서 누르기,
낮춘 힘 기준, 클릭·드래그 해제 후 이동 중 압력 변화, 누름 중 중심 좌표 이동,
압력이 흔들리는 드래그, 같은 접촉에서 96ms에 걸친 두 번의 누름·해제,
일반 탭·더블탭과 추가 탭 억제, 다중 터치, 센서 중단, 접촉/클릭 해제 보고 누락을 검사합니다.
검사를 통과한 뒤 왼쪽·오른쪽·설정 초기화 펌웨어를 빌드합니다.

실기기에서의 감도와 멈춤 현상 해소 여부는 빌드 성공만으로 보장할 수 없습니다.
이동 → 정지 후 포스터치 → 연속 두 번 누르기 → 드래그 → 손 떼기 → 일반 더블탭
순서로 확인합니다. TP 레이어가 해제되는지도 확인합니다.
이번 반응 개선 변경은 오른쪽 펌웨어에만 있습니다. 직전 안정화 버전을 양쪽에
적용했다면 오른쪽만 갱신하면 됩니다. LCD 아이콘과 배치는 변경하지 않습니다.
