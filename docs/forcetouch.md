# 입력 지연 수정과 센서값 확인 (v6)

## 입력 전달

기존 ZMK v0.3 BLE 마우스 전송 함수는 큐가 차면 입력 스레드에서 최대 100ms씩
기다리고 재시도했습니다. 이번 버전은 이 함수만 링크 래퍼로 교체합니다.
입력 스레드는 기다리지 않고 보고를 등록하며, 별도의 마우스 전송 스레드가
기존 암호화 HID 서비스로 보냅니다. 키보드 HID 전송 작업 큐와도 분리됩니다.

동일한 버튼 상태의 연속 이동은 합칩니다. 누름/뗌 경계를 넘어서 합치지 않으므로
일반 탭과 포스터치 더블클릭의 네 번의 버튼 변화는 순서대로 보존됩니다.
블루투스 스택에는 마우스 보고를 한 건씩 넣고 전송 완료 후 다음 것을 보냅니다.
40ms보다 오래된 대기 이동은 버리며, 오래된 버튼 변화는 유지합니다.
이는 40ms를 기다렸다 보내는 설정이 아닙니다. 보낼 수 있으면 즉시 보냅니다.

16건을 넘는 비정상적인 버튼 변화 폭주에서는 해제 상태와 최신 상태로 복구합니다.
연결별로 큐를 분리하고 연결이 끊기면 비웁니다. 일반 이동은 10분간 125Hz를 넣고
소비 속도를 2~125Hz로 바꿔도 대기 이동 보고가 한 건을 넘지 않는지 검사합니다.

좌우 키보드의 X/Y 묶음 전송은 유지합니다. PC 연결은 7.5ms 간격, 지연 허용 0을
요청하지만 실제 간격은 PC가 결정합니다. 센서 보고 설정 8ms가 실제 전체 입력
지연 또는 PC 수신 주기를 보증하지는 않습니다. 무선 환경/실기기 검증은 별도입니다.

## 클릭, 이동과 프레스 홀드

일반 커서 이동은 탭 200ms와 홀드 300ms 판정을 기다리지 않습니다.
클릭을 해제한 뒤 재클릭 준비 구간 250ms 동안 커서까지 계속 멈추던 처리를
제거했습니다. 이 구간은 접촉 기준값 유지에만 사용하며, 의도적인 이동은 즉시
일반 이동 처리로 돌아갑니다.

힘을 주기 시작한 실제 포스터치 후보, 눌린 버튼의 클릭 흔들림 억제는 유지합니다.
포스터치 누름 뒤 180ms 동안의 이동은 버리고, 그 이후 24 센서 단위를 넘는
이동은 드래그로 전환합니다. 움직이던 중 강도만 바뀌어서 클릭되는 것은 막습니다.
클릭 준비 중 불완전한 누름 억제는 최대 80ms입니다.

처음 손을 댄 위치에서 가만히 300ms 유지하면 프레스 홀드가 작동합니다.
설정은 tap-time 200ms + hold-time 100ms입니다. 그 뒤 움직이면 드래그하고,
손을 떼면 해제합니다. 처음부터 움직였던 접촉은 자동 홀드로 바뀌지 않습니다.
단순 탭은 200ms 이내/16 센서 단위 이내 접촉을 뗄 때 즉시 클릭합니다.

압력 임계값은 이번에 변경하지 않았습니다. 안정 접촉 기준 B에 대해
C = B + max(30, ceil(B * 8 / 100)) 이상이 16ms 유지되면 누름입니다.
해제는 B + max(16, ceil(B * 3 / 100)) 이하가 16ms 유지될 때입니다.
손을 떼지 않고 충분히 힘을 빼고 다시 누르면 다음 누름을 판정합니다.
더블클릭의 최종 시간/위치 판정은 PC 운영체제가 합니다. 실기기에서 성공했다고
확인하지 않은 상태이며, 수치 표시로 누름과 해제 조건을 확인할 수 있습니다.

## LCD 센서값

아이콘 그림, 크기, 위치와 정렬은 그대로입니다. 진단을 위해 그 아래의 레이어명과
USB/BLE 문자열 영역만 다음 네 줄로 대체합니다. 오른쪽 연결 프로필 점은 유지합니다.

- S: 현재 접촉 강도 센서값. 손을 떼면 0이며 새 보고가 없으면 --입니다.
- B: 현재 클릭 판정의 접촉 기준값. 초기 접촉 안정화/일반 이동 때 조정됩니다.
- C: 실제 설정으로 계산한 누름 기준값. 기준이 아직 준비되지 않으면 --입니다.
- P: 이번 접촉의 최고 센서값. 손을 뗀 뒤에도 다음 접촉 전까지 남습니다.

가볍게 댄 S와 B, 세게 눌렀을 때 S/P와 C를 비교합니다. 이 값은 g 또는 N 같은
물리적인 힘 단위가 아닙니다. 감도 비교를 위한 센서의 접촉 강도입니다.

현재값/기준값은 ABS 0x1a, 최고값/누름 증가량은 ABS 0x1b로 보냅니다.
이동/버튼 처리가 끝난 뒤 K_NO_WAIT로 등록합니다. 최대 200ms마다 두 건이고,
일반 이동 중에는 보내지 않습니다. LCD 그리기도 최대 5Hz, 바뀐 줄만 갱신합니다.
기존 상태 아이콘/TP 복구용 ABS 0x18과 좌표 묶음 ABS 0x19는 유지합니다.

## 검증과 적용

같은 C 판정 코드로 클릭/더블클릭, 이동 우선 처리, 클릭 중 흔들림 억제,
300ms 홀드, 탭, 드래그, 다중 터치/센서 중단/TP 레이어 해제 복구를 검사합니다.
전송 큐는 장시간 과부하, 버튼 순서, 오래된 이동 제거, 실패한 알림 재시도,
범위 포화와 연결 초기화를 검사합니다. CI에서는 ASan/UBSan 후 좌우를 빌드합니다.
빌드 성공은 실제 키보드에서 버벅임이 없어졌다는 확인을 대신하지 않습니다.

이번 버전은 왼쪽에 BLE 전송/LCD 수정, 오른쪽에 이동 억제/300ms 홀드/센서값
전송 수정이 있으므로 양쪽 모두 갱신해야 합니다. 설정 초기화는 필요하지 않습니다.
