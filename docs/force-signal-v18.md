# 설정 숫자와 센서값의 의미

## 무엇이 고정되어 있는가

v17/v18의 클릭 설정은 Touch Strength와 직접 비교하는 고정 숫자입니다. 처음 손가락을 댔을 때의 강도를 빼거나, 그 값의 비율로 기준을 다시 정하지 않습니다. 정지/이동에는 각각 저장된 고정 기준을 사용합니다. 설정을 바꾼 경우 다음 접촉부터 새 설정 묶음을 사용합니다.

현재 기기에서 읽은 설정은 정지 억제 2750, 정지 클릭 3500, 해제 2200, 이동 억제 3250, 이동 클릭 4000입니다. 이 조회값은 이번 측정 당시 값이며 사용자가 이후 조절하면 달라집니다.

## 트랙패드가 내보내는 값

IQS5xx-B000 데이터시트 3.3.4에서는 채널의 Delta를 Count − Reference로 정의합니다. 3.4에서는 Reference가 사용자 접촉이 없을 때 환경 변화를 따라 갱신되고, 사용자 접촉 중에는 갱신되지 않는다고 설명합니다. 5.2.4에서 Touch Strength는 한 손가락에 연결된 채널들의 Delta 합이며 센서 감도 설정에 따라 달라진다고 명시합니다.

따라서 Touch Strength는 센서가 계산해서 보내는 접촉 신호의 크기입니다. 전 프레임과의 차이나 최초 손가락 접촉값과의 차이를 뜻하지 않습니다. 보정 전 정전용량의 절대 측정값도 아니고, 뉴턴·그램으로 측정한 물리적인 힘도 아닙니다. 고정된 Touch Strength 숫자가 모든 손가락·접촉 자세에서 같은 물리적인 힘을 뜻한다고 보장할 수 없습니다.

드라이버는 0x001A~0x001B의 2바이트 값을 읽고 그대로 판정 함수에 전달합니다. 진단 기록에서 '원시값'이라고 부르는 것은 펌웨어가 추가 보정하지 않은 이 레지스터값을 뜻하며, 센서 내부의 보정 전 Count 자체를 뜻하지 않습니다. 표현 범위 0~65535와 실제 측정 범위·유용한 조절 범위는 서로 다릅니다.

## v17 측정에서 확인한 것

829개 기록에서 강도 3509에 클릭 누름이 발생했고 PC에서도 누름이 관측됐습니다. 기록 중 강도가 해제 기준 2200 이하로 내려오지 않았으며, PC에서는 약 7.92초 동안 버튼이 눌려 있었습니다. 이 기록은 '클릭 누름이 전혀 전달되지 않음'과 '누름 이후 해제되지 않아 다음 클릭을 받을 수 없음'을 구분하는 근거입니다.

안내 신호의 예정 시각과 실제 접촉 시작 시각이 일치하지 않았습니다. 따라서 안내 구간의 통계만으로 가벼운 접촉·원하는 누름·힘 풀기의 최종 기준을 확정하지 않습니다. LCD 숫자 수신 복구 후 사용자 동작과 값을 대응시켜 클릭과 해제를 함께 조절해야 합니다. v18은 저장된 기준을 임의로 바꾸지 않습니다.
