# v4 드래그 전환 거리 조정

기준 펌웨어는 `a8fb5a119eebc207e17ac76665518a645621703f` (v4)입니다.
포스터치 클릭 후 작은 손가락 좌표 변화가 드래그로 바뀌는 것을 줄이기 위해,
드래그 전환 거리를 각 축 기준 24에서 48 센서 단위로 높였습니다.
48까지는 클릭 위치를 유지하고, 48을 초과하면 같은 센서 보고에서 드래그를 시작합니다.
추가 시간 대기는 없습니다. 실제 손가락 이동 거리(mm)로 환산한 값은 아닙니다.

클릭 강도 기준(최소 증가량 30, 기준값의 8%), 해제 기준, 일반 탭, 더블클릭,
센서 이동 처리, LCD 및 아이콘은 v4를 유지합니다.
클릭 후보를 취소하는 이동 거리는 기존 72로 분리하여, 드래그 거리 조정 때문에
클릭 자체가 더 쉽게 인정되는 부수 효과를 막았습니다.

드래그 조정은 오른쪽 펌웨어에 적용됩니다. 함께 추가한 BLE 변경은 왼쪽에
적용되며 [BLE 변경 설명](v4-ble-latency.md)을 참고합니다.

검증: 클릭 상태의 ±48 흔들림, 49에서 즉시 드래그 전환, 시작한 드래그의 연속성,
손을 떼지 않는 두 번 클릭, 기존 72의 클릭 후보 이동 제한, 일반 탭과 해제 복구.
자동 검사는 상태 판정 코드에 대한 것이며 실제 기기의 사용감 검증은 별도입니다.
