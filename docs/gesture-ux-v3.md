# 터치 동작 조정

기준: BLE 전송 2차 수정 `b438410cfb3c4e88d9b25a5390d4fac3c27abdcb`.
사용자는 빨라졌지만 아직 일반 마우스보다 느리며, 포스터치·두 손가락 스크롤 이후 더 느려진다고 보고했다.

## 동작

- 시작된 드래그는 단일 손가락의 접촉이 유효한 동안 힘이 줄어도 유지한다. 손을 떼거나 센서 오류·접촉 유실·다중 접촉이 생기면 해제한다.
- 드래그가 아닌 클릭은 초기 접촉 기준값까지 완전히 돌아오지 않아도, 누른 뒤 최고 센서값에서 정지 클릭 역치만큼 내려가면 해제를 판정한다. 16ms 확인 시간은 유지한다.
- 클릭을 해제한 센서값을 다음 클릭의 기준으로 즉시 사용한다. 별도의 더블클릭 대기 시간이나 이동을 멈추는 추가 타이머는 없다.
- 정지 중 클릭 기준은 증가량 30과 기준값의 8% 중 큰 값이다. 이동 중에는 증가량 90과 24% 중 큰 값을 사용한다. 이는 물리적인 힘의 단위가 아닌 센서값의 초깃값이며 사용자 실측 보정 전이다.
- 이동 후 32ms 동안 의도적인 이동이 없으면 정지 기준으로 돌아온다. 이 시간은 클릭 판정용이며 커서 이동을 지연시키지 않는다. 정지 직후 누른 힘을 이동 기준값에 바로 흡수하지 않는다.
- 이동 중 강하게 누른 후보는 높은 역치를 유지한 채 확인한다. 정지 중 누르면서 생기는 작은 위치 변화는 계속 허용한다.
- 세 손가락 탭은 모두 뗄 때 가운데 버튼을 한 번 클릭한다. 첫 접촉부터 200ms 이내, 동일 손가락 수 상태에서 이동 16 센서 단위 이내를 기준으로 한다. 세 손가락을 차례로 대거나 떼면서 좌표 중심이 변하는 것은 이동으로 처리하지 않는다. 길게 누르기·밀기·네 손가락·오류는 클릭하지 않는다.
- 세 손가락 접촉에서는 중복 오른쪽/왼쪽 탭을 막는다. 두 손가락 스크롤/확대 표식이 남아도 손가락이 하나로 줄면 일반 이동 경로로 돌아간다.

## 조절 위치

`boards/shields/toucan/toucan_right.overlay`에서 정지/이동 역치와 정지 복귀 시간, 클릭 확인 시간, 드래그 시작 거리(48)를 따로 조절한다. 아이콘 모양·배치, 왼쪽 BLE 전송 코드와 설정은 변경하지 않는다.

## 검증과 남은 확인

원래 코드에서 첫 클릭을 완전히 이완하지 않고 다시 누르는 입력을 넣으면 해제가 나오지 않는 것을 검사로 재현했다. 수정 후 두 클릭, 압력 0을 포함한 드래그 유지, 해제/오류 복구, 이동 중 낮은 증가량 차단과 높은 증가량 허용, 세 손가락 탭 및 스크롤 종료 분기를 검사한다.

PC Raw Input 후속 기록에서 이동 보고 중앙 간격은 약 15ms로 이전 약 30ms보다 줄었다. 다만 측정 시작 응답이 늦어 안내 전 동작이 섞였고, 이번 기록을 통제된 연속 이동 비교나 포스터치 이후 지연의 확정 원인으로 사용하지 않는다. 실제 남은 지연과 체감 일관성은 이 펌웨어 적용 후 확인이 필요하다.
