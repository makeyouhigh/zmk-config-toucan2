# v17 포스터치 설정 화면과 조절 제한

SYS(7번 레이어)에서 Y/H는 이동 억제 +100/-100, U/J는 클릭 +100/-100, I/K는 해제 +100/-100이다. 허용 범위는 다음과 같다.

| 기준 | 정지 최솟값 | 정지 최댓값 | 이동 최솟값 | 이동 최댓값 |
| --- | ---: | ---: | ---: | ---: |
| 이동 억제 | 1500 | 5000 | 2000 | 5500 |
| 클릭 | 2000 | 6000 | 2500 | 6500 |
| 해제 | 1000 | 4000 | 1000 | 4000 |

원시 센서값 기준이다. 하드웨어의 물리적 힘이나 실제 센서 최솟값/최댓값을 나타내지 않는다. 기존 기록의 가벼운/평소 접촉 약 2500~3600, 의도한 누름 약 4000~5500을 참고해 조절 범위를 제안했고, 사용자의 요청대로 최솟값을 각각 1500 더 낮췄다.

범위 안에서도 해제 < 억제 < 클릭 및 이동 중 억제 < 클릭을 지켜야 한다. 범위나 순서를 벗어나는 명령은 일부만 적용하지 않고 전부 거절한다. 정지 기준과 이동 기준은 함께 바뀌며 기존 +500 간격을 유지한다. 변경은 다음 접촉부터 판정에 반영되고 손을 뗀 뒤 저장되어 재부팅 후 유지된다.

SYS 화면의 REST는 정지, MOVE는 이동 중 기준이다. 숫자는 오른쪽 설정 담당 코드에서 받은 실제 값이며, 왼쪽에서 키 입력을 세어 추정하지 않는다. 조회 중에는 ----와 WAIT RIGHT를 표시한다. 오른쪽이 끊어졌을 때도 이전 숫자를 현재 값인 것처럼 표시하지 않는다. LCD는 3개의 같은 세대 표시 이벤트를 모두 받았을 때만 한꺼번에 갱신한다. 별도의 표시용 입력 이벤트는 마우스 HID를 발생시키지 않는다. 평소 LCD 배치는 유지한다.

조회는 SYS 진입과 오른쪽 연결 시에만, 추가 표시는 설정 명령 시에만 실행한다. 센서 프레임별 전송/장기 재시도/커서 이동 누적은 추가하지 않는다. 오른쪽의 설정값 전송 큐와 왼쪽 조회 재시도는 유한하게 제한한다.

현재 저장값(억제 3550·클릭 4500·해제 3000)은 유지한다. v17 양쪽 적용 후 패드에서 손을 떼고 SYS J를 5회 누르면 클릭은 4000, 이동 중 클릭은 4500이다. H/K는 다시 누르지 않는다. 실제 값은 LCD나 USB의 LEVELS,v17,2 응답으로 확인한다. 저장값이 새 범위/순서를 위반한 경우 기본값 4250/4500/4000을 사용하므로 LCD에서 확인할 수 있다.

U/J의 실제 기기 이름은 v16에서 짧게 고친 fclk_up/fclk_dn을 사용한다. Keymap Editor의 fclick_up/fclick_dn 라벨과 표시 이름은 유지한다. ZMK Studio에 별도로 저장한 긴 이름 기반 U/J 바인딩은 재지정이 필요할 수 있다. 페어링과 저장 키맵을 일괄 초기화하지 않는다.
