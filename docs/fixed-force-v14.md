# v14 고정 기준 포스터치

포스터치 판정을 다시 작성했습니다. 기준값은 사용자가 정한 원시 센서 숫자이며, 접촉 시작값이나 직전 클릭에 따라 학습하지 않습니다.

| 동작 | 고정 Touch Strength |
| --- | --- |
| 정지 상태 이동 억제 시작 | 4250 |
| 정지 상태 클릭 | 4500 |
| 이동 중 이동 억제 시작 | 4750 |
| 이동 중 클릭 | 5000 |
| 힘을 풀어 클릭 해제 | 4000 이하 |

이 설정은 boards/shields/toucan/toucan_right.overlay의 force-*-level입니다. 모두 16비트 원시값입니다. 표현 가능한 숫자 범위 0~65535가 실제 사용 중 측정 범위나 물리적인 힘의 범위를 뜻하지 않습니다. 조건 순서는 해제 < 이동 억제 < 클릭이며, 이동 중 수준은 정지 수준 이상이어야 합니다. 잘못된 순서는 빌드에서 거절합니다.

정지/이동 두 가지 사전 설정만 선택합니다. 이동을 멈춘 후 32ms가 지나면 정지 설정으로 돌아옵니다. 힘이 이동 억제 수준에 도달하면 해당 클릭에 사용할 설정을 고정하므로, 누르면서 손가락 중심이 흔들려도 클릭 수준이 올라가지 않습니다. 최초 접촉부터 클릭 수준 이상이면 같은 8ms 확인 후 클릭합니다.

클릭 수준 이상이 8ms 유지되면 버튼을 누릅니다. 해제 수준 이하가 들어오면 즉시 버튼을 놓고 다음 클릭을 받을 수 있습니다. 두 번째 누름의 세기나 클릭 간격에 대한 별도 보정은 없습니다. PC가 두 번의 누름·해제를 더블클릭으로 판단합니다. 센서 보고 사이에 끝난 변화는 관측할 수 없습니다.

삭제한 것: 최초 접촉 평균/안정화, 기준값 비율, 이동 중 기준값 추적, 클릭 최고점 추적, 낮아진 골짜기로 기준 재설정, 400ms 특별 재클릭 역치, 얕은 재상승을 추가 클릭으로 나누는 예외. 같은 원시값을 입력하면 접촉 시작 강도와 직전 클릭 횟수에 관계없이 같은 고정 수준을 적용합니다.

250ms 접촉 홀드 후 이동하는 드래그와, 포스 클릭 300ms 유지 후 이동하는 드래그를 지원합니다. 드래그가 시작되면 강도가 낮아져도 손을 뗄 때까지 유지합니다. 다중 접촉/잘못된 접촉/250ms 센서 기록 중단은 해제합니다. 초기 홀드는 12좌표 단위의 접촉 흔들림을 허용하고, 홀드 이후 이동은 120ms 안에 48단위를 넘어야 하므로 천천히 정밀 이동하다 뒤늦게 드래그로 바뀌는 것을 제한합니다.

보통 이동에는 대기열이나 지연을 추가하지 않습니다. 클릭 전단계와 클릭 중의 상대 이동은 버리고 나중에 재생하지 않습니다. 일반 탭, 두 손가락 스크롤, 세 손가락 탭 가운데 클릭과 LCD 배치를 유지합니다. 왼쪽 BLE 코드는 변경하지 않았습니다. 과거의 약 1초 누적 지연 원인은 이번 판정 재작성만으로 해결됐다고 주장하지 않습니다.

## 키보드에서 감도 조절

7번 SYS 레이어에서 다음 키를 한 번 누를 때 100씩 조절합니다. 키를 누르고 있는 동안 자동 반복하지 않습니다.

| 조절 대상 | +100 | −100 | behavior 명령 |
| --- | --- | --- | --- |
| 이동 억제 수준 | Y | H | FORCE_LOCK_UP / FORCE_LOCK_DOWN |
| 클릭 수준 | U | J | FORCE_CLICK_UP / FORCE_CLICK_DOWN |
| 해제 수준 | I | K | FORCE_RELEASE_UP / FORCE_RELEASE_DOWN |

예: `&force_cfg FORCE_CLICK_UP 100`. ZMK Studio의 '포스터치 기준' behavior에서도 명령과 조절량 1~2000을 지정할 수 있습니다. `&force_cfg FORCE_RESET 0`은 위 표의 초기값으로 복원하며 기본 키에는 배치하지 않았습니다.

이동 억제/클릭을 바꾸면 이동 중 수준도 같은 양만큼 바뀌어 +500 차이를 유지합니다. 해제 < 이동 억제 < 클릭의 순서와 1~65535 범위를 벗어나는 조작은 전체를 거절하며 일부 값만 바꾸지 않습니다. 따라서 값이 경계에 닿으면 이웃 기준을 먼저 조절해야 합니다.

클릭 값을 높이면 더 큰 센서값에서 클릭합니다. 이동 억제 값을 높이면 더 큰 센서값에 도달해야 커서가 멈춥니다. 해제 값을 높이면 힘을 덜 풀어도 클릭이 해제되어 다음 클릭을 받을 수 있습니다.

오른쪽에 연결되어 있어야 명령이 적용됩니다. 어느 쪽에서 키를 눌러도 ZMK의 global behavior 전달 경로로 오른쪽 센서 설정을 바꿉니다. 현재 접촉의 판정은 유지하고 다음 접촉부터 새 값을 적용합니다. 마지막 조절 후 1초가 지난 때부터 손이 떨어져 있으면 설정을 저장하며, 계속 접촉 중이면 1초마다 저장을 미룹니다. 일반 터치/클릭은 저장 작업을 만들지 않습니다. 저장이 끝나면 재부팅 후에도 유지합니다.

이번 버전은 behavior 등록과 SYS 키맵을 위해 양쪽을 모두 적용합니다. ZMK Studio로 저장된 키맵이 있다면 펌웨어 기본 SYS 배치보다 우선할 수 있습니다. 이때 해당 여섯 자리만 위 behavior로 바꾸고 저장하십시오. 기존 키맵을 자동 초기화하지 않습니다.

오른쪽 USB 진단 포트에서 `tools/read-force-levels.ps1 -Port COM14`로 현재 설정 다섯 값을 읽을 수 있습니다. COM 번호는 실제 연결에 맞춥니다. LCD 배치는 바꾸지 않습니다.

## 측정과 검증

기존 v12의 원시값을 높은 소리 1/2/3/4회로 안내해 가벼운 접촉/평소 접촉/원하는 클릭 세기/이탈 순서로 기록했습니다. 사용자가 안내를 듣고 수행했다고 확인한 세 번째 기록만 사용합니다. 낮은 소리를 듣지 못한 앞선 두 기록은 감도 설정 근거에서 제외합니다. 각 단계 첫 1.5초를 제외하고 원시값을 비교했으며, 자동 기준값과 예전 클릭 성공 여부는 감도 추정에 사용하지 않았습니다. 실제 원시 기록은 로컬에 보관합니다.

이 숫자는 한 번의 개인별 측정에서 정한 첫 설정이며, 여러 손가락/위치에서의 편안함은 실기기 확인이 필요합니다. 이후 조정도 같은 고정 숫자를 명시적으로 바꾸는 방식으로 진행하며 자동으로 다시 학습하지 않습니다.

진단 프로토콜은 v14,2이며 기록은 60바이트입니다. 원시 강도/면적/좌표와 실제 적용된 이동 억제/클릭/해제 수준을 함께 남깁니다. 구형 v11~v13 기록 해석은 도구에서 유지하지만 판정 코드는 남기지 않습니다.

검사: 최초 접촉 강도가 다른 경우, 처음부터 세게 접촉, 동일/더 낮은 두 번째 최고값, 한 보고 길이의 해제, 3000회 반복 클릭, 이동 중 고정 수준, 이동 즉시 재개, 250ms 홀드, 느린 정밀 이동, 드래그 이탈 해제, 반복 일반/세 손가락 탭, 잘못된 접촉 및 센서 중단, 진단 원시값/수준 해석. 이 검사는 실제 착용 환경의 클릭 성공률 또는 전체 BLE 지연 측정이 아닙니다.
