# v22 — USB 진단 제거와 최종 정리

사용자가 v21 적용 후 동작이 좋아졌다고 확인하여, 같은 클릭·드래그 판정을 유지한 정리 버전입니다. 감도나 시간 조건을 새로 조정하지 않습니다.

□ 제거: 오른쪽 USB CDC 센서 진단 포트, 진단 스니펫과 Kconfig, 1536개 센서 기록 버퍼(92160바이트), 전용 기록 스레드, 프레임별 시각·반환값·상태 기록, 진단 전용 상태 필드, PC 진단 명령·해석 스크립트와 그 전용 검사.

□ 제거: 초기화 시 레지스터 전체 덤프와 전원 상태 로그만을 위한 추가 I2C 읽기. 초기화의 통신 종료 쓰기는 유지합니다. 저전력 강제 통신 뒤에는 기존 추가 읽기 대신 200µs 대기를 넣어 센서의 최소 150µs 준비 시간을 보장합니다. 이 대기는 전원 상태 변경 경로에만 있으며 센서 프레임마다 실행되지 않습니다. 근거: [Azoteq IQS5xx 데이터시트 8.8.2](https://www.azoteq.com/images/stories/pdf/iqs5xx-b000_trackpad_datasheet.pdf).

□ 유지: 완결된 포스클릭 펄스와 빠른 재누름, 포스클릭의 드래그 전환 금지, 별도 250ms 정지 홀드 후 이동 드래그, 일반 탭·세 손가락 탭, BLE 전송, 터치/버튼 고착 복구, 설정 저장·조절, SYS 숫자와 TP 실시간 숫자 및 기존 LCD 배치.

□ 왼쪽 ZMK Studio의 USB 키맵 편집은 진단 기능이 아니므로 유지합니다. 기존 일반 드라이버 로그 매크로는 소스에 남겨 두며, 배포 빌드에서 실제 로그·콘솔 백엔드 활성 여부를 별도로 확인합니다.

□ 펌웨어에서 실행하지 않는 클릭·전송·LCD 회귀 검사는 유지합니다. 사용자 센서 원시 기록은 PC에만 보관하며 GitHub에 올리지 않습니다. 로컬 재생에서 v21과 v22의 모든 클릭 이벤트와 종료 상태가 일치했습니다. 20개 구간 중 19개 두 클릭과 고정 역치 미달 1개 단일 클릭이라는 기존 결과도 동일합니다. 재생 결과를 실기기 성공률로 해석하지 않습니다.

□ 적용 전 양쪽 빌드, 실제 Kconfig, UF2 무결성과 왼쪽 바이너리 동일 여부를 검증합니다. 검증된 소스 커밋·빌드 링크·파일 해시는 FIRMWARE_VERSIONS.md에 기록합니다. 저장값을 지우는 초기화 펌웨어는 필요하지 않습니다.
